Privacy policy

TaxReceiptSyncr · last updated 16 October 2026

TaxReceiptSyncr is a personal tool written and used only by Glenn Reilly ("the author"), on his own Google account. It is not offered to the public. This policy explains what the app does with Google user data.

What the app accesses

  • Gmail (gmail.modify): reads email messages that carry the author's receipts label, including attachments, and applies the labels receipts-done or receipts-needs-review. It does not delete messages.
  • Gmail (gmail.send): sends a short summary email from the author's address to the same address after a run.
  • Google Drive (drive): finds and creates folders and uploads receipt PDFs. Full Drive access is needed because narrower access cannot see the author's existing tax folders. The app only creates folders and files inside one designated tax folder. It also searches Drive for files carrying its own marker, to avoid uploading the same receipt twice.

How the data is used

Receipts and invoices are read from the author's mailbox, converted to PDF where necessary, and uploaded to the author's own Google Drive. That is the only purpose. The app runs on GitHub Actions and processes data in memory for the duration of a run.

Sharing, selling and advertising

The app does not share, sell or transfer Google user data to anyone. It does not use Google user data for advertising, profiling or training machine-learning models, and no person reads the data other than the author, in his own mailbox and Drive.

Storage and retention

  • The app has no database and keeps no copy of your mail or receipts. The only stored output is the PDFs uploaded to the author's own Google Drive.
  • Run logs contain only counts, file names and email message IDs. They never contain email bodies, receipt contents or access tokens.
  • The OAuth refresh token is stored as an encrypted secret in a private GitHub repository.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. After that the app can no longer read Gmail or Drive.

Google API Services User Data Policy

TaxReceiptSyncr's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
